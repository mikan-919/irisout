# 設計

選択要素の参照は配列側の更新で無効にし、連続した選択で前回のキーを引き直さない。委譲中の行は同期処理中だけ選択の手掛かりに使い、再入・配列更新で無効にする。操作と無関係な要素をクリックごとに探索しない。所有する配列の純粋filterは二重のコールバックを除く。親を専有する一覧について、境界コメントと汎用DOM操作を省ける条件を別に検証する。既定のイベントの契約、古い行の参照、例外・再入を維持する。

専有一覧だけを反映し通知先がない更新は、更新取引への呼出しを省く。単独の固定位置交換は添字順からDOMを直接移動し、値の再照合と実行時の隣接判定を省く。通知先がある場合は従来経路を使う。通知の開始に失敗した場合も添字順を無効にし、通知解除後に旧行を直接交換しない。変更前後の同期時間とVanillaとの差は別に測定する。
