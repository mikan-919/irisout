# 設計

一般の一覧照合へ省略可能なレコード生成関数を渡し、平坦な行の状態を参照時にだけ確保する。状態の同一性と既存の生成関数の呼出しは維持する。初期テキストは新規複製の形状を利用する。通常更新の検査は残す。

構造操作は配列の所有判定と基点の識別子を使う。キーが不変の保持行を更新しない条件を検証し、対象外は従来経路へ戻す。配列や行の破壊的変更を一括して許可しない。

mapの先頭が行の展開である場合、後続の上書きフィールドを記録して更新関数に渡す。キーを変更しない場合はキー検証を省く。mapは配列複製を維持する。交換の複製は非共有性を追加検査し、複製と設定の間の呼出し・例外も除外した場合だけ省く。行オブジェクトは古いイベント内参照を保つため確保を続ける。追加の既存部分の複製は生成関数の呼出し前に行う。
