## Context

`generateModule()`は行配列へ文字列を追加し、最後に改行で連結する。`analyzeExpr()`は作者記述を
書き換えた文字列を返すが、その文字列が元ソースのどこから来たかを出力型へ残していない。
`compileProject()`は連結したソース範囲から元モジュールへ戻す情報を診断用に保持している。
Vite連携の`load()`は現在JavaScript文字列だけを返す。

## Goals / Non-Goals

**Goals:**

- 作者記述から生成した断片について、生成位置と元モジュール位置を保持する。
- 位置対応のない生成処理を誤った元位置へ割り当てない。
- 既存の生成JavaScriptを変えずに位置対応情報を追加する。

**Non-Goals:**

- 共有実行時処理とすべての自動生成行を元JSXへ対応付けること。
- 要求ごとのサーバー描画や、実行時の例外回復を追加すること。
- ソースマップ対応だけを理由に生成器全体を汎用AST生成へ移行すること。

## Decisions

### 1. 生成文字列と相対位置対応を一つの断片として渡す

解析結果へ、生成文字列内の開始位置と連結ソース上の開始位置を持つ対応表を追加する。
コンパイラは`HandlerOutput`、`ActionOutput`、`MountOutput`、`EffectOutput`へ必要な対応表を渡す。
生成器は断片を行へ埋め込んだ時点で、相対生成位置をモジュール全体の位置へ変換する。

元文字列を生成後に検索する案は採用しない。同じ処理文が複数ある場合と、識別子や状態更新を
書き換えた場合に一意に対応できないためである。

### 2. Source Map v3を`CompileResult`へ追加する

`CompileResult`へJSONとして直列化できるSource Map v3の値を追加する。地図生成には
Source Map v3の区間生成を行う専用ライブラリを直接依存として使い、可変長整数符号化を
独自実装しない。ソース本文を`sourceContent`へ含め、開発者道具が元ファイルを別途取得
できない場合も表示できるようにする。

注: Source Map v3は、生成位置と元位置を相対値で圧縮して記録する共通形式である。

### 3. `compileProject()`で既存の元モジュール範囲を再利用する

単一文字列の`compile()`は元ファイル名を`<source>`とする。`compileProject()`は診断で使う
連結範囲を再利用し、各位置を入口または子モジュールへ戻す。外部モジュールの内部は
コンパイルしないため、irisout側のソースマップ対象に含めない。

### 4. Viteの仮想モジュール読込結果で地図を返す

Vite連携の`load()`は文字列ではなく`{ code, map }`を返す。自動`hydrate`文は作者記述と
対応しないため地図へ登録しない。Vite+は開発時にこの地図を使い、本番ビルドでは利用者が
`build.sourcemap: true`を指定した場合に後続変換と合成する。

### 5. 例外位置の試験は地図の照会と本番出力の両方で行う

コンパイラ試験は生成位置を地図から照会し、期待する元ファイル、行、列と比較する。
Vite連携試験は仮想モジュールの読込結果が地図を含むことを確認する。別アプリ試験は
外部ソースマップを生成し、対象の対応が本番出力にも残ることを確認する。ブラウザごとの
スタック文字列だけには依存しない。

## Risks / Trade-offs

- [生成断片の改行や書き換えで列対応がずれる] → 断片内の対応点を解析時に記録し、同じ文が
  複数ある試験と状態読み書きの書き換え試験を追加する。
- [地図生成でコンパイル時間とメモリが増える] → 作者記述由来の断片だけを記録し、性能測定で
  増加が確認された場合は地図生成の有効化条件を別途決める。
- [未対応行が直前の対応区間へ誤って解釈される] → 生成断片の終端に無対応区間を置き、共有処理を
  元JSXへ引き延ばさない試験を追加する。
- [公開`CompileResult`の型が変わる] → 既存フィールドを変更せず、地図フィールドを追加する。

## Migration Plan

コンパイラ、Vite連携、単一公開パッケージの順に同じ版で出力を更新する。既存利用者の設定変更は
不要である。本番の外部地図が必要な利用者だけが`build.sourcemap: true`を指定する。問題が
見つかった場合はVite連携から地図を返さない状態へ戻せるよう、生成JavaScriptと地図を分離する。
