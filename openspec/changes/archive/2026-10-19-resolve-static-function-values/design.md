# 設計

`function-binding.ts`が束縛の同一性と再代入の有無を調べ、const別名と仮引数を同じ関数ノードへ解決する。仮引数は所有関数の全参照から直接呼出しを列挙し、全実引数が同じ本体へ解決することを検査する。呼出し自体は置換せず、読取り依存・書込み候補・関数出力・後始末への参照を同じ解決へ接続する。

保存した更新・後始末関数の返却は、返却識別子ごとに実行契約を記録する。後始末では従来の更新なしの生成物へ接続し、const別名の評価を残す。初期化・通常呼出しと後始末が共用する関数の本体を上書きしない。後始末へ関数引数を渡す場合は、関数同一性を観測する形を位置付き診断で残す。

`generated-names.ts`は作者の予約接頭辞を一時名で分離し、生成後に内部束縛だけを移して作者名を戻す。大域参照、関数名、仮引数、オブジェクトとSSR入力の省略形を保持する。生成物の位置編集を行い、位置マーカーの再整形を避ける。

本体の外から呼ぶ補助関数も状態参照を検査する。そこへ通常の本体用の反映を流用しない。再代入、異なる実引数、動的関数値、外部へ渡された呼出先、ジェネレーター、正規authoring API名とのトップレベル衝突は対象外。
