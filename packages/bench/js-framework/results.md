## 修正前後の同期処理時間（ms）

同じJSXを修正前（fbb8601）と修正後で構築し、同じブラウザーで順序を交互にして測定した。3回の事前実行後に15試行。選択は200回、交換は20回の操作から1回当たりを求める。同期したイベント処理とDOM書き込みの時間であり、レイアウト・描画を含まない。上の公式測定とは別の指標。

| 操作                 |  修正前 |  修正後 | 修正前÷修正後 |
| -------------------- | ------: | ------: | ------------: |
| 1,000行作成          |  4.4700 |  3.1600 |          1.41 |
| 1,000行置換          | 10.5800 | 10.3250 |          1.02 |
| 10行ごとに更新       |  0.5050 |  0.3450 |          1.46 |
| 行選択               |  0.0033 |  0.0037 |          0.88 |
| 2行交換              |  0.1675 |  0.0738 |          2.27 |
| 1行削除              |  0.2850 |  0.2750 |          1.04 |
| 10,000行作成         | 50.7200 | 37.8100 |          1.34 |
| 1,000行へ1,000行追加 |  5.5800 |  4.2300 |          1.32 |
| 全行削除             |  3.9550 |  4.2800 |          0.92 |

直接読み込む生成スクリプトのgzip合計は3.66→3.80KiB。HTMLと共通CSSはこの値に含まない。

全試行値は[optimization.json](./optimization.json)を参照。

## 解釈の範囲

単一環境での測定であり、一般のアプリ全体の性能順位を示さない。React・Vue・Solidは上流の実装と構築設定を維持した。irisoutは宣言した状態と一覧から生成し、手書きのDOM操作や測定専用の実行時最適化を加えていない。生の全試行値、script/paint内訳、版情報は[results.json](./results.json)を参照。再実行は[README.md](./README.md)を参照。
