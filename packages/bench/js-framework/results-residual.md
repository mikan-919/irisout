# js-framework-benchmark 比較結果

同じ環境で上流の本番実装と公式測定器を実行した結果。公開ランキングとは測定環境が異なる。

## 条件

- 測定日時: 2026-10-17T06:45:15.247Z
- 上流: [krausest/js-framework-benchmark](https://github.com/krausest/js-framework-benchmark/tree/bf894b681fb56433ccb6efb4a3c93e35eda2b20d)
- irisout: c1e7e015c48a54db0accd5e4ea3cfdb89742f79d の作業木。実装と環境情報はこのディレクトリに保存。
- ブラウザー: Google Chrome for Testing 153.0.8010.12、画面を表示しない方式、1280×800。
- CPU: AMD Ryzen 7 7700 8-Core Processor、論理16個。linux 6.18.33.2-microsoft-standard-WSL2 x64。
- Node v24.22.0、Bun 1.3.13。
- すべてキー付き一覧。上流のisKeyed検査でDOM構造と作成・削除・交換時の要素再利用を確認。
- CPUは各10回、選択は上流の追加試行により20回。メモリは各3回、転送量と初回描画は各1回。値は中央値。
- 上流の事前実行回数とCPU減速設定を維持。CPU値はクリックから描画までのtotal。03のx16、08のx2、09のx8は上流の識別名で、表に追加の乗除算をしていない。

## 解釈の範囲

単一環境での測定であり、一般のアプリ全体の性能順位を示さない。React・Vue・Solidは上流の実装と構築設定を維持した。irisoutは宣言した状態と一覧から生成し、手書きのDOM操作や測定専用の実行時最適化を加えていない。生の全試行値、script/paint内訳、版情報は[results-residual.json](./results-residual.json)を参照。再実行は[README.md](./README.md)を参照。
