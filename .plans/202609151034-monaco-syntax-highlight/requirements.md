# Goal

PlaygroundのMonaco Editorで、JSXを含む入力ソースを構文要素ごとに色分けして表示する。

# Terms

D1 構文ハイライト: Monacoの言語トークナイザーによるキーワード、文字列、コメント、JSXタグ、JSX属性などの色分け。補完、意味解析、エラー診断は含まない。

D2 Monaco入力欄: Monaco Editorの読込みに成功したときに表示する`[data-playground-monaco]`の編集欄。読込みに失敗した場合は既存の`textarea`を使う。

# Req

R1 Monaco入力欄は、Playgroundが扱うJavaScriptとJSXの入力を対応する言語定義で表示し、初期値に含まれるキーワード、文字列、コメント、JSXタグ、JSX属性を色分けする。

R2 利用者の編集、例の切替え、共有値の複製などでソース値が置き換わっても、同じ言語定義による構文ハイライトを維持する。

R3 構文ハイライトの導入後も、Monacoの編集値と既存の`textarea`の値を同期し、保存、書き出し、実行が同じソース値を参照する。

R4 Monacoまたはその言語機能の遅延読込みに失敗した場合は、構文ハイライトを要求するために入力を失わせず、既存の`textarea`で入力、保存、書き出しを継続できる。

R5 構文ハイライトは編集画面の表示機能に限定し、投稿ソースの変換・実行、実行管理画面、別配信元の境界を変更しない。

# Constraints

K1 既存の`monaco-editor` 0.56.0、遅延読込み、作業スレッド設定を使う。別の構文解析・色分け依存を追加しない。

K2 対象言語は現在のPlaygroundの単一JavaScript/JSX入力に限る。TypeScript固有の型機能や複数ファイル編集は対象にしない。

K3 既存のテーマ、読取り専用状態、アクセシビリティ属性、入力失敗時の退避動作を保つ。

# Non-goals

N1 入力補完、整形、意味解析、診断メッセージ、リンターの追加。

N2 ドキュメント生成側のコード表示や、Playground以外の編集欄への構文ハイライト追加。

N3 利用者がテーマや言語を選ぶ機能。

# Done

A1 [R1] Monaco読込み後のPlaygroundで、JavaScript/JSXの代表的なキーワード、文字列、コメント、JSXタグ、JSX属性がテキスト表示と異なる色で表示される。

A2 [R1,R2] 初期ソース、例の切替え、共有値の複製、Monaco上の編集の各経路で、表示されたソースが構文ハイライトを維持する。

A3 [R3,R4,R5] 既存の入力同期、読取り専用状態、保存、書き出し、実行、Monaco読込み失敗時の`textarea`フォールバックが変わらない。

A4 [K1,K2,K3] `bun run typecheck:web`と`bun run test:web:playground`が成功する。
