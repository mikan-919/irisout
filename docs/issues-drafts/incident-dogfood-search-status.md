# 検索失敗時に完了と失敗を同時表示する

観測日: 2026-10-08。独立操作役の原文:

> 失敗検索時に「検索完了」と「検索に失敗しました」が同時に残りました。

## 再現と対応

追試Bの一覧で「失敗」を検索する。APIはHTTP503を返す。処理中かどうかだけで表示を選んでいたため、成功と失敗の区別なく「検索完了」になった。アプリの表示式へ失敗状態の分岐を加えた。本体と文書の受入条件は変更していない。

修正前も課題の8項目は合格していた。操作役の負の観測を合格結果とは別に記録し、修正後は該当項目だけを再検査した。HTTP503で「検索失敗」と失敗通知が出て「検索完了」は出ない。次の「通知」検索でエラーが消え、通知遅延だけを表示した。原文と結果は`fixtures/incident-dogfood/evidence/b-status-fix.json`。
