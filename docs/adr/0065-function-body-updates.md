# ADR-0065: 関数本体の制御フローを保持する状態反映

障害対応ボードの試用で、内部の関数宣言が拒否された。調査では、末尾に更新文を追加する変換に由来する返却の制限と、非同期補助関数の更新漏れも再現した。ハンドラー、補助関数、内部の関数は共通の解析へ通し、JavaScriptの文と返り値を保持する。通常の関数は書込みを実行したか記録し、`finally`で専用の更新処理を呼ぶ。これにより返却と例外による終了でも状態を反映し、書込み前の返却ではeffectを再実行しない。

同期補助関数は呼出し側でまとめて反映する。呼出し側は追跡呼出し式の評価開始を更新の根拠とし、静的過剰近似を残す。引数の評価が例外で終了した場合にも更新処理を呼びうる。非同期補助関数と内部コールバックは、自分の実行の終了時に反映する。所有範囲とeffectの書込み禁止の検査には、非同期処理も含む全書込み集合を使う。実行時の更新集合と所有範囲の検査集合を分ける。

文の種類ごとに許可を増やす案は、同じ出口の問題を補助関数とコールバックで繰り返すため採らない。書込みのたびに即時反映する案は、同期の複数書込みを一度に反映する契約を変えるため採らない。汎用の実行時購読機構は追加しない。アクションや`onMount`の初期化本体は、末尾から返す関数が本体の変数を参照できる形を維持する。この初期化本体の途中返却制限は残り、通常の関数と区別して説明する。

ADR-0009の文種と書込み後返却の制限、およびADR-0013の局所関数呼出しと非同期更新の判断を改訂する。残る境界と受入条件は`openspec/specs/handler-statement-bodies/`、`cross-function-handler-writes/`、`element-use-action/`を参照する。
