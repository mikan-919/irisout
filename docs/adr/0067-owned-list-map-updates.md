# ADR-0067: 所有する配列のmapを変更行へ接続する

状態: 決定済み。日付: 2026-10-16。

ADR-0066では配列更新の後に全行のキー照合と値評価が残っていた。通常のsignal APIを維持し、配列と行が外部へ漏れず、行が自身のプリミティブ値（文字列・数値・真偽値・nullなど）だけを持つと確認できる場合に限り、純粋なmapで変更した行を記録する。行の参照が同じという理由だけで一般の一覧更新を省略することはしない。

## 適用条件

対象はルートの非共有signalである。初期値は行のオブジェクトリテラルからなる配列とする。後の新規行もオブジェクトリテラル、または関数内で作る空配列へ新規行をpushして返す関数から供給する。値がオブジェクトや関数にならないことを式から確認する。行と配列を未知の呼出し、別の状態、書込み式の返り値へ渡す場合は適用しない。配列のsliceによる複製と位置交換は、参照がその関数内に留まり、行の値を書き換えない場合に受理する。非同期に複製配列を書き換える場合も対象外とする。

mapは、引数の行、行の展開を含む新しい行、またはそれらの条件式を返す式本体のarrowに限る。添字と行の直接のプロパティ読み取り、リテラルの計算を受理し、呼出しや代入を含むmapは対象外とする。プロトタイプからオブジェクトや関数を持ち込まないため、mapと表示で読むフィールドは全作成経路に共通する自身のプロパティに限る。フィルターは行を外へ渡さず値を書き換えない場合だけ受理する。

一覧側は直接のキーとテキスト読み取り、およびADR-0066の選択属性だけを持つ平坦な項目に限る。一般の式、共有状態、局所状態、要求単位SSR、入れ子、ライフサイクルには既存の経路を使う。対象外の記述を新たにコンパイルエラーにはしない。

## 生成と実行

1. 対象の`rows(rows().map(callback))`を変更行を記録する配列生成へ変換する。通常はmapと同じ回数だけcallbackを実行する。
2. 条件が`index % stride === offset`または`index === offset`で、非該当時に元の行を返す場合は、sliceで配列を複製し、該当位置だけcallbackを実行する。正の整数の間隔と非負整数の位置だけを受理する。配列の空き位置を保持する。参照の複製は配列長に比例するが、式の評価と行の検索は変更数に比例する。
3. 配列ごとのWeakMapに基点の識別子と変更した行の組を保存する。基点の配列自体を記録せず、更新履歴による配列の保持を避ける。各一覧の基点は別のWeakMapで保持し、同じ配列を複数の一覧へ反映できる。
4. 一覧が最後に反映した配列と基点が一致し、変更行のキーがすべて変わらず、別の本文依存も同時に変わらなければ、その行だけを既存の共有更新関数へ渡す。全キー照合とDOM順序の確認を省く。
5. キー変更、複数mapの未反映、他の依存の同時変更では通常照合へ戻す。反映前に基点を無効化し、例外後に部分更新を続行しない。通常照合後は基点を更新する。

行の直接更新用APIや汎用の購読処理は追加しない。行のオブジェクトをその場で変更する案は、イベント処理内に残る古い行の参照が観測する値を変えるため採用しない。

## 検証

生成コードの実行で1,000行中100行の更新が100回の行検索になることを確認する。交換・削除・置換後、複数書込み、他の依存、別名参照、関数呼出し、重複キー、独立した一覧、例外後の再反映、インライン化された部品を検査する。添字範囲のcallback実行位置と空き位置も検査する。同一ブラウザーで修正前後とSolidを交互に測定し、描画を含む既存の公式値とは区別して保存する。
