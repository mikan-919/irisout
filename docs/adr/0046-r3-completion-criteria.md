# ADR-0046: R3性能目標の改訂と完了判定

## ステータス

**決定済み・R3完了**(2026-09-09)

## 背景

R3は、同一環境の現行基準に対してTodoMVC 1万件の初期化中央値を20%以上短縮することを
仮目標としていた。ADR-0044の初回List経路改善では82.7msから69.9msへ15.5%短縮した。
ADR-0045の初期条件分岐DOM再利用を変更前コミット`e645893`と同じ条件で比較すると、
86.6msから74.0msへ14.5%短縮した。二つの比較は基準値が異なるため合算しない。

最終実装の内訳では、初期化64.6msのうちList reconcileが57.3ms、item factoryが
46.5ms、初期branch factoryが7.5msだった。時間は処理の入れ子を含む。残る費用の中心は、
項目ごとのDOM複製、管理情報作成、目印探索、直接イベント登録である。

親要素へのイベント委譲は登録費用を減らせるが、`currentTarget`、イベント段階、`blur`、
event objectの同一性を変える。条件分岐DOM再利用の適用拡大は、初期値の評価、副作用、
ライフサイクル、入れ子構造、SVG名前空間の規則を増やす。20%との差を埋めることだけを
理由に、これらの契約や対応範囲を変更しない。

## 決定

- 20%以上という固定値をR3の完了条件から外す。
- 同一Chromium、同一入力、同一反復数、同一初期化区間による変更前後の比較で、
  1万件の初期化中央値に測定のばらつきを超える短縮があり、原因分析と再現方法を記録
  できたことを性能改善の完了条件とする。
- 100件・1,000件、通常更新、転送量、JavaScriptヒープ、既存機能を併せて確認し、
  悪化と採否を記録する。
- 現行実装の14.5%短縮を採用する。100件の+0.1ms、gzip合計の+74B、N=1,000の
  mount後ヒープの+5,756Bは、1万件の短縮とイベント契約の維持に対して許容する。
- 親要素へのイベント委譲と、条件分岐DOM再利用の一般化はR3へ追加しない。
- Reactとの比較は参考値として残す。初期HTMLの扱いと初期化方式が異なるため、React以下を
  R3の完了条件にしない。

## 結果

R3は、原因分析、二つの採用変更、再現可能な比較、操作数の検査、通常更新・転送量・
ヒープの記録を満たしたため完了とする。性能値は単一環境の測定結果であり、ページ読み込み
から操作可能になるまでの時間や、異なる端末での体感速度を保証しない。

次はR4の作者以外による手動導入試用へ進む。試用で初期化時間が停止要因になる事例が
得られた場合は、対象の入力規模とイベント契約を示した別の変更として再検討する。

注: イベント委譲とは、各要素ではなく祖先要素へイベント処理を登録し、発生元から処理対象を
判定する方式である。登録数は減るが、直接登録と同じイベントの意味を保てるとは限らない。
