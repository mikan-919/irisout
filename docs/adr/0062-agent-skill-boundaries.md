# ADR-0062: 利用側アプリと本体開発のSkillを分ける

## ステータス

決定済み(2026-09-26)

## 背景

従来の`irisout-development`は利用側アプリ向けに配布していたが、名前から本体開発にも
適用されやすい。導入済みの版には本体開発時の手順も含まれ、作業の境界が曖昧になっていた。

## 決定

- `irisout`を公開パッケージに依存する別プロジェクトのアプリ用Skillとする。
- `irisout-development`をirisoutソースリポジトリ内の開発用Skillとする。
- 既存の利用側アプリ向け導入先は`irisout`へ切り替える。旧名の内容を利用側アプリ用として維持しない。
- 各Skillの説明文に対象外の作業を記載し、選択時点で区別できるようにする。

## 検討した代替案

- 旧名の説明だけを修正する案: 既存名が本体開発を示すため、説明と名前のずれが残る。
- 一つのSkillに両方の手順を入れる案: 選択時に作業対象を区別できず、誤適用が再発する。
