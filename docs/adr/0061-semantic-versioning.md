# ADR-0061: リリース版にセマンティックバージョニングを使う

## 状態

採用

## 背景

公開版の番号から、利用者が変更の範囲と互換性を判断できるようにする。

## 決定

特別な指定がない場合、`MAJOR.MINOR.PATCH`に従って版を決める。

- 後方互換性を保つ不具合修正は`PATCH`を上げる。
- 後方互換性を保つ機能追加は`MINOR`を上げる。
- 公開APIに後方互換性のない変更は`MAJOR`を上げる。
- `0.x`の間は公開APIの互換性を保証せず、後方互換性のない変更は`MINOR`を上げる。`PATCH`には互換性を保つ変更だけを含める。
- 明示された公開版の指定は通常の増分規則より優先する。

`packages/irisout/package.json`、`packages/irisout/CHANGELOG.md`、導入文書、公開tagには同じ版を記載する。

## 結果

版番号と変更範囲を一貫して対応付けられる。公開後は`latest` tagを当該版へ更新する。
