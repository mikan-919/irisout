# ADR-0050: 0.1.1の版範囲と梱包検査

## ステータス

**採用・公開済み**(2026-09-10)

## 背景

0.1.0公開後に、隔離試用で見つかった診断と利用文書の不足を修正し、イベント処理、`use=`、`onMount`、`effect`の実行時ソースマップを追加した。従来の梱包検査は型検査、本番構築、初期HTML、生成JavaScriptを確認したが、公開tarballから読み込んだVite連携がソースマップを本番生成物へ渡すことは確認していなかった。

## 決定

- 公開入口の削除と既存記法の変更がないため、0.1.0以後の変更を0.1.1として扱う。
- 公開する`irisout`だけを0.1.1へ更新する。非公開の内部作業領域パッケージの版は連動させない。
- `pack:smoke`はtarballのREADME、変更履歴、ライセンス、公開入口を確認する。
- `pack:smoke`が作る一時アプリは本番ソースマップを出力し、生成されたイベント処理の位置から一時アプリの`src/App.jsx`と行番号を取得できることを確認する。
- 変更履歴を公開tarballへ含める。
- この変更ではnpmへ公開しない。公開後は版を固定した登録先検査を別に実行する。

## 結果

公開tarballだけを使う検査が、型定義、Vite連携、初期HTML、実行時処理に加えて実行時ソースマップを対象に含む。0.1.1が未公開である間、導入文書のコマンドは公開済み0.1.0を指し続ける。
0.1.1を2026-09-10にnpmへ公開し、版を固定した登録先検査で型検査、本番構築、初期HTML、イベント処理、ソースマップを確認した。
