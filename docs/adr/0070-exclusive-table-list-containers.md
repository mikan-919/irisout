# ADR-0070: 選択参照の保持と表の専有親

日付: 2026-10-17。状態: 採用。

Vanillaとの差をコードと呼出し回数で照合すると、選択済みの行の再検索、無関係なクリック対象の探索、filterを包むコールバック、交換時の親・隣接参照、全削除時の境界の再挿入が残っていた。

選択参照は連続した選択の間だけ保持する。配列の反映前に無効にし、失敗後や再入で古い行を使わない。委譲中の行は同期処理中だけ選択先の手掛かりにし、配列更新と処理終了で消す。削除済みの行の検査は継続する。委譲の経路は保存済みの要素から判定し、未保存の対象は該当する深さだけで解決する。通常のHTML要素の選択classはclassNameへ設定し、SVG・カスタム要素・isの属性設定は維持する。

通常配列と純粋な述語を確認したfilterは、元の長さ・欠けた添字・評価順を維持する一つのループへ下げる。公開の汎用filterヘルパーは変更しない。DOM更新の通知先がない場合は空の集合を走査しない。

クライアントの最上位一覧がtbody・thead・tfootの全内容で、所有配列の証明があり、著者コードからDOMを取得する経路がない場合は、親そのものを一覧の格納先とする。ルート入力、外部import、未知の大域参照、イベント引数、action・ライフサイクル、カスタム要素・SVG・slot、反射的な関数取得、動的importを含む記述は対象外とする。行は通常の表示用要素に限り、リンク先・編集・フォーカス指定を持つ記述も対象外とする。対象外の記述は拒否せず境界コメントを保つ。

専有親では交換先を保持済みの添字順から取得し、親や隣接節点を読まない。全削除はtextContentへの一回の設定とする。全置換の行は先にすべて作成し、例外が出る前に旧DOMを消さない。空の節への追加時だけ節を外し、最後に元の親と位置へ戻す。既存行への追加では節を外さない。親要素の同一性は維持する。外部から管理対象へ挿入したDOMや、著者コードに現れない外部のRangeの観測は、この閉じた一覧の証明対象に含めない。DOMを外部へ渡す公開経路がある記述は従来処理を保つ。要求SSRにも従来の境界を保つ。

これらは処理の削減を定めるもので、全操作の時間がVanilla以下になる保証ではない。試行値と生成物を固定し、同期時間と描画を含む公式時間を分けて検証する。

2026-10-17の追加検証で、交換の記録だけを一覧へ渡す試作は200試行で短縮を確認できず、採用しなかった。固定位置の原子的な交換で、配列の描画先が専有一覧一つだけ、派生値なし、書込み先が配列一つだけ、ほかの呼出し・入れ子関数なしと確認できるハンドラは、汎用記録を作らず専用の更新へ接続する。範囲外の位置では配列複製を保つ。DOM更新の通知前に添字順を無効にし、通知中の再入・例外後は通常照合へ戻す。交換前の行参照と交換後の配列が対応する場合だけDOMを移す。成功時は順序を保存し、選択参照を保つ。複数一覧と他の依存は従来処理を保つ。

委譲の通常要素では、最も浅いイベント対象より上を走査しない。専有親の全削除は、Vanillaと同じく旧行への管理参照を先に解放してからDOMを消す。空から作成するときも親を消去し、消去失敗後の再作成で旧行を残さない。

DOMを外部へ渡さない専有一覧の委譲は、親参照を辿り、イベント経路の配列と行のMap再検索を省く。この一覧の削除済みの行は親への経路を失うため、親の登録へイベントが届かない。外部コードによる古い行の再挿入は専有の証明対象外である。通常の一覧はcomposedPathと削除済み記録の検査を保つ。Text節点からのイベントと行内の祖先ハンドラも処理する。

専有一覧だけを反映する更新では、通知先がない間は更新取引の開始・終了を呼ばない。通知先の有無はランタイムの生きた束縛で共有し、mount後の登録・解除も反映する。更新開始時に通知の要否を保存し、開始後に最後の通知先が解除されても取引を終了する。通常の一覧、ライフサイクルとDOMの公開経路はこの省略の対象外とする。

単独の原子的な固定位置交換には、通知先がなく、更新取引の外にあり、反映済みの添字順が有効な場合の直接処理を生成する。行と配列の値の対応検査、配列長の一致検査、親の存在検査、位置の隣接判定と共有ヘルパー呼出しを省く。添字の範囲は検査し、隣接かどうかはコンパイル時に決める。移動に失敗した場合は添字順を無効のままにする。専有一覧を含む通常更新と複数状態の一括更新でも、通知開始前から失敗を捕捉して添字順を無効にする。同じ長さの新配列を設定してから通知が例外になった場合にも、次の交換が旧行を移動しないことを保証する。通知先がある交換と取引中の交換は従来の再入検査を保つ。最後の通知先が更新前の通知中に解除されて再入しても、外側の取引が続く間は旧行を直接交換しない。
