# ADR-0051: キー付き配列状態をsignalへ統合する

## ステータス

決定済み・実装済み(2026-09-11)。

## コンテキスト

`signal(initial)`と`collection(initial, keyOf)`は読み取りと全体設定の形が同じだが、キー付き配列だけ別の宣言関数を要求していた。状態の宣言方法を一つにしながら、キー索引による一項目更新を維持する必要がある。

## 決定

`signal(initial, keyOf)`をキー付き配列状態として受理する。返り値は通常のsignalと同じ読み取り・全体設定に加え、`update(key, updater)`を持つ。`collection()`は作者向けAPIから削除し、互換別名を提供しない。

コンパイラは`signal`の引数数で通常状態とキー付き配列状態を区別する。キー索引、一覧項目への直接通知、module共有時の購読は既存経路を使う。

## 結果

作者は状態を`signal`だけで宣言できる。旧`collection()`を使うコードは`signal(initial, keyOf)`への移行が必要になる。内部のキー付き状態処理は実装詳細として残す。
