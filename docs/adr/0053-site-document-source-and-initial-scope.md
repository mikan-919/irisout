# ADR-0053: 公式文書の正本と初回掲載範囲

- **状態**: 決定済み・実装済み（実運用未検証）
- **日付**: 2026-09-14

## コンテキスト

公式サイトは静的HTMLを生成する文書サイトとして整備する。現在の導入手順は
`docs/getting-started.md`にあり、`app/web`にはCounter・List・SVGの動作確認画面がある。
同じ説明をサイト用ディレクトリへコピーすると、本文と導入手順の二重管理が生じる。

## 決定

- `docs/getting-started.md`を導入文書の正本とする。SSGはこのファイルを入力として参照し、
  内容を`app/web`のJSXへ二重記載しない。
- 初回の文書分類は「導入」「状態と更新」「イベント」「条件分岐と一覧」「部品とファイル
  分割」「ライフサイクル」「API」「診断と対応範囲」とする。
- 初回の公式例はCounter、List、SVGとする。表示用コードとPlayground入力は同じ例の入力から
  生成する。
- 文書はJavaScriptなしの直接URLで読める静的HTMLとし、Playgroundのコンパイラを文書用の
  配信物へ含めない。

## 検討した代替案

- **導入文書を`app/web/content/docs`へ移す**: サイト内の配置は揃うが、リポジトリ内の既存
  参照先が変わり、移動案内が必要になるため初回は採用しない。
- **既存文書とサイト文書を別々に保守する**: 修正漏れで導入手順とサイト表示が分かれるため
  採用しない。
- **初回から全ての既存例を掲載する**: 例の検査範囲とサイトの受入条件が広がるため、現行の
  3例を基準にする。

## 結果

文書の変更元を追跡でき、導入手順とサイトの表示に差が出ない。初回の公開範囲は既存の
Counter・List・SVGで検証でき、追加分類や例は別の変更として扱える。文書SSGのMarkdown
解析器とコード強調表示器は、任意HTMLを受け付けない実装と自動検査で確認した。実運用の
配信物と作者以外の手動試用は未検証である。
