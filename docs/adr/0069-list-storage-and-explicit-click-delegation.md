# ADR-0069: 一覧の参照寿命と添字順を保持し、click委譲を明示契約として分ける

状態: 実装・検証済み。日付: 2026-10-16。

## 根拠

[Vanillaのコード調査](../../packages/bench/js-framework/vanilla-code-review.md)で、作成後に使わない参照、管理用オブジェクトの重複、添字からの再検索、全置換の新旧走査、断片への追加と直接登録の費用を確認した。

## 決定

1. 平坦な行の作成用参照と更新用参照を分け、イベントにだけ使う要素を更新用の保存領域へ残さない。根の参照には`el`を使う。所有する行のプリミティブなキーフィールドだけを表示する本文は、同じキーの寿命中に変わらないため、更新用の要素参照・表示文字列・比較を省く。所有関係を証明できない行には適用しない。
2. 生成側の`FlatListHandle`を行の記録としても使い、包みを各行1個省く。公開の実行時関数へ従来の生成関数を渡す場合は互換の包みを保つ。項目状態とbindingsは参照時の確保と同一性を維持する。
3. 通常照合で作った順序配列を次の操作へ保持する。mapは変更の添字・変更前・変更後を一つの配列へ記録し、組ごとの配列確保を省く。map・交換・削除は保持した添字順から描画対象を引く。追加は末尾へ記録し、単一削除はsplice、複数削除は一回の詰め直しを使う。照合開始時に順序と基点を無効にし、失敗後は通常照合へ戻す。行と元配列の値の契約は変更しない。
4. 親を専有する全置換は、旧DOMを一括で置換した後、Mapを空にして新しい記録だけを登録する。新旧合計の走査と旧キーごとの削除を省く。キー検索と重複検出は維持する。作成の例外が起きる前に旧DOMを消す方式は採用しない。
5. 通常要素だけの行は、すべての作成を終えてから親へ直接挿入できる。一時断片への追加を省く。カスタム要素、is、入れ子、ライフサイクルのある行は断片を維持する。親を文書から外す方式は、親の焦点や接続状態を変えるため採用しない。開始・終了アンカーと静的兄弟は維持する。
6. コンパイラとViteに`listEvents: 'delegated'`を追加する。既定は`'direct'`であり、ADR-0021のネイティブイベント契約を維持する。委譲はルートの平坦な一覧の引数なし`onClick`だけに適用し、引数付きclick、blur、入れ子、ライフサイクルは直接登録を保つ。対象行の根へ一つの非公開Symbolを付け、削除リンクは作成時に探索しない。親で受ける方式を明示的に選ぶため、非バブルのclick、途中の伝播停止、外部リスナーとの実行順は直接方式と一致しない。イベントの代理オブジェクトは作らない。削除済みの記録は処理せず、unmount時に親の登録を解除する。
7. ベンチマークのJSXは変更せず、構築設定で委譲を選ぶ。`JSFB_LIST_EVENTS=direct`で既定の契約も比較できる。直接配線の修正前・修正後と、委譲を使った修正後を分けて測定し、速度とメモリに加えて転送量の増減を報告する。

## 代替案

- 自動的な委譲への切替はイベントの観測を変えるため採用しない。
- 行への書込みや配列複製の省略はこの変更に含めない。古い行の参照と例外時の状態を保つ。
- 添字順の記録を持たず、毎回Mapから引く方式は調査で確認した再検索を残す。順序配列の保持費用はメモリ計測へ含める。
- 全置換でキーが新しいと推測して先に破棄する方式は採用しない。キー再利用と作成例外の意味を保つ。

## 検証と残差

全516試験、型検査、梱包、実例・文書、Motion・Playground、3画面幅と8操作、公式5実装のキー付き判定を通過した。直接方式を含む全9操作各100試行、Vanillaとの独立2組、公式CPU各10回（選択20回）・メモリ各3回・転送量各1回を保存した。

修正前の直接方式と修正後の委譲との同期比較では、作成・置換・部分更新・追加を短縮した。一方、選択と削除は増加した。委譲は作成費用との交換条件を持つため、既定を切り替えず明示設定として採用する。順序配列を保持する費用と削除時の詰め直しも残る。全体時間では作成2種・1行削除・全削除でVanillaとの差を確認し、全操作でVanilla以下には達していない。作成後メモリは別実行の2.134→2.042MiB、Brotli転送量は4.7→5.0KiBとなった。[全試行値と95%区間](../../packages/bench/js-framework/code-work-results.md)を判断の根拠とする。
