# ADR-0068: 一覧の作成と所有配列の操作を必要な行へ限定する

状態: 決定済み、実装中。日付: 2026-10-16。

## 根拠

[再検証](../../packages/bench/js-framework/vanilla-audit.md)で、単純な行の未使用状態の確保、複製直後の形状確認、構造変更時の保持行の照合が残った。[計画](../reports/2026-10-16-list-performance-plan.md)の条件に沿って削除する。

## 決定

1. 状態を受け取らない平坦な行には専用のレコード生成関数を渡す。`record.state`を外から参照した場合は従来と同じ項目専用の状態を初回に作る。一般の生成関数とライフサイクル経路には従来の生成を使う。
2. テンプレートの根をテンプレート自身に保持する。複製直後の初期テキストは既知の節点へ書き、通常更新では子構造の復元規則を維持する。初期属性と直接イベント登録の意味は変えない。
3. 所有配列の操作を証明できる場合、既存の基点照合へ操作の記録を接続する。基点が一致しない場合、他の依存の同時変更、例外後は通常照合へ戻す。記録は元配列の参照を保持せず、連鎖した履歴を作らない。
4. 配列と行の複製を省く条件は分ける。既存の所有判定だけで行をその場で書き換えない。イベント中の古い行参照と例外時の状態を保つ。
5. 時間、メモリ、転送量、処理回数を測り、改善を確認した単位を保存する。測定専用のJSXやDOM操作、イベント委譲は導入しない。
