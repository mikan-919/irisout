# ADR-0058: SSRの相対モジュールを要求スコープへ閉じ込める

状態: 決定済み

要求単位SSRで相対モジュールを許可する。リンクした補助関数と補助定数は生成moduleの共有領域ではなく`render()`内へ配置し、要求ごとに作り直す。module共有`signal()`と`derived()`は引き続き拒否する。

外部importは一律にサーバーで解決しない。SSRで実行される宣言とHTML式から到達するbindingはscope limitとして拒否し、イベント、ライフサイクル、actionだけが参照するbindingはSSR生成物から除外する。これによりブラウザー専用モジュールを持つpageでも、サーバーがその処理を読み込まずに初期HTMLを生成できる。

Honoのファイル経路はVite連携と同じ`transformSource`境界を受け取る。Motionなどの任意拡張はコンパイラ本体へ個別対応を追加せず、標準irisout記法へ変換してからSSRする。
