# 検証ログのドッグフーディング

確認日: 2026-10-08

## 目的

irisout開発で再現した問題を、再現内容・期待結果・実際の結果と対応状態をまとめて記録する画面を用意した。作者以外の友人を前提にせず、独立したサブエージェントに初回利用者として操作を依頼した。

## 操作

- `bun run dev:notes`で開発画面を起動した。
- 空のブラウザー状態で検証記録を作り、再読み込み後の保持を確認した。
- 本文内の語句で検索し、存在しない語句で空状態になることを確認した。
- タイトルを編集して保存し、一覧への反映を確認した。
- 未解決から解決済みへ切り替え、解決済み一覧での表示と再読み込み後の保持を確認した。

## 観測と修正

最初の操作では、一覧の状態切替が`tab`役割だったため、ボタンとして探索する操作から見つけにくかった。状態の絞り込みはナビゲーションボタンであるため、通常のボタンに変更して`aria-pressed`で選択状態を伝えるようにした。

状態を解決済みにすると記録が現在の一覧から消え、移動先が分かりにくかった。切替後の通知を「解決済み一覧に移動しました。」または「未解決一覧に戻しました。」へ変更した。修正後、独立したエージェントが新しいブラウザー状態で同じ操作をやり直し、各操作を画面から完了した。

再読み込み後は未解決一覧を初期表示する。解決済み記録も保存され、解決済みボタンから再表示できることを確認した。検索文字列と一覧フィルターの選択状態は再読み込み後に初期値へ戻る。

## 実行条件と結果

- 開発サーバー: `bun run dev:notes`、`127.0.0.1:5173`
- ブラウザー: NixOS Chromium 154.0.8037.57、Playwright 1.61.1
- ブラウザー状態: 新しいcontext、1280×900
- 初回操作担当は実装差分と画面ソースを見ずに実行した。
- 作成、再読み込み、本文検索、編集、解決状態切替、移動先通知、解決済み一覧、再読み込み後の再表示を確認した。
- localStorageの読取り・書込み失敗、空白タイトルの拒否はDOM試験で確認した。
- `bun run check`: 書式・型検査通過、0 errors、18 warnings。
- `bun run test`: 45 files、344 tests passed。
- `IRISOUT_ENTRY=notes.jsx bun run --cwd apps/demos build`: 成功。
